# AdSense 合格戦略 & ads.txt 運用

宅建マスター（takken-master.jp）を Google AdSense で確実に合格させ、
「有用性の低いコンテンツ（価値の低い広告枠 / スケーラブルなコンテンツの
不正使用）」で不合格にならないための方針と、実施済みの対策をまとめる。

---

## 1. ads.txt が「不明」のままだった原因と対処

- **原因**: サイトのルートに `ads.txt` が存在しなかった。ファイルが無いと
  Google クローラは永久に「不明（見つかりません）」と表示する。
- **対処**: ルートに `ads.txt` を追加した（GitHub Pages がそのまま
  `https://takken-master.jp/ads.txt` として配信する）。
- **残作業（要パブリッシャー ID）**: `ads.txt` 内のプレースホルダ
  `pub-XXXXXXXXXXXXXXXX` を実際の AdSense サイト運営者 ID に置き換え、
  行頭のコメント記号を外して有効化する。手順はファイル冒頭のコメント参照。

### 併せて必要（承認審査で判定される）: 検証スニペット

AdSense の審査・広告配信には、各ページ `<head>` に以下のスニペットが必要。
これもパブリッシャー ID を入れて全ページへ挿入する（未実施 / ID 待ち）。

```html
<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX" crossorigin="anonymous"></script>
```

挿入は各ビルダの `<head>` テンプレート、または一括パッチツールで行う
（GA4 の `site-analytics.js` と同じ位置が目安）。

---

## 2. 「有用性の低いコンテンツ」対策 — 何がリスクだったか

サイトは 7,000 以上の静的ページを持つが、審査で問題になるのは
**大量に自動生成されたテンプレート的な薄いページ**である。調査で判明した点：

1. **実践演習 `/q/practice/`（AI 自動生成・約 1,000 ページ）**
   - 解説がテンプレートの使い回し（設問文を言い換えて再掲するだけの循環説明）。
   - 一部に**事実誤認**（例: 低廉な空家等の報酬特例の上限を「30万円」と誤記。
     正しくは税別 18 万円）。受験者にも有害。
   - → AdSense の「有用性の低いコンテンツ」に該当する最大リスク。

2. **壊れた定型文の混入（過去問・実践演習・orig の 314 ページ）**
   - 組合せ肢のフォールバック解説に、宅建と無関係な労働安全衛生の
     「作業主任者の選任が必要な作業の組合せ…」という別試験の文言が
     誤って注入されていた（`enrich_past_explanation_choices.py` のバグ）。

3. **一問一答 `/q/ichimon/`**
   - 既に全ページ noindex 済み（サイト内演習用）。リスクなし。

---

## 3. 実施した対策（このブランチ）

方針: **「除外しつつ順次改善」**（審査中は薄いページをインデックスから外し、
検証済みのものを段階的に戻す）。

| 対策 | 内容 | 効果 |
|---|---|---|
| 実践演習を noindex 化 | `q/practice/p*` の約 1,000 ページを noindex に反転。生成元 `build_practice_ichimon_pages.py` も `practice_robots_meta()` を使うよう変更し、再ビルドしても維持されるようにした | インデックス対象から 1,000 ページの低品質ページを除外 |
| 壊れた定型文を除去 | 「作業主任者…」の誤注入を中立で正しい文言へ置換（CSV 源泉 `data/past_questions.csv`・`data/practice_questions.csv` と、デプロイ済み HTML 314 ページの両方）。生成元 `enrich_past_explanation_choices.py` のフォールバックも修正 | 過去問（保持）の品質欠陥を解消。再発防止 |
| sitemap 再生成 | `build_sitemap.py` を実行。noindex ページは自動除外される | 登録 URL **1,954 → 954**（過去問・記事・用語解説の手書き中心に） |

### 審査に露出する（index 維持の）コンテンツ

- **過去問 `/q/past/`（482）**: 実際の国家試験問題。価値の高い正当なコンテンツ。
- **用語解説 `/terms/`（355）**: 手書き・手直しの用語ページ。
- **試験ガイド `/articles/`（52）**: 手書きの記事。
- 各セクションの一覧・ハブページ、静的ページ（about / privacy 等）。

→ 合計 **954 URL**。すべて人手の検証・編集を経た、または実試験由来の
コンテンツで、AdSense 審査に安心して出せるプロフィール。

---

## 4. 順次改善（合格後 / 継続運用）

実践演習を index に戻す場合は、**人手で内容を検証してから**行う。

1. 問題文・正答・解説の事実確認（特に報酬・数値・期間などの数値論点）。
2. テンプレートの循環説明を、条文根拠・具体例入りの実質的な解説へ書き換え。
3. 検証済みの問題 ID を `tools/q_content_quality.py` の
   `PRACTICE_INDEX_ALLOWLIST` に追加。
4. 該当ページを再ビルドし（`practice_robots_meta()` が allowlist の ID を
   index に戻す）、`build_sitemap.py` で sitemap を再生成。

> 一度に大量へ戻さない。検証済みの良質な問題だけを少しずつ index に加えることで、
> サイト平均品質を保ったままカバレッジを広げる。
