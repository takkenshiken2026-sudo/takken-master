宅建の頻出論点まとめ｜分野別・絶対暗記の数字一覧

宅建は50問・4分野ですが、出題の型は年々繰り返されます。2026年度は10月18日（日）試験・受験料8,200円（RETIO要項が正本）。本記事では業法・権利・法令制限・税の頻出テーマと数字（5営業日・8日・2週間等）の優先順位、用語解説と過去問演習への落とし込み、直前2週間の見直し方を表で整理します。一覧は「全部暗記」より過去問で落とした項目を追加する運用が現実的です。

この記事の要点

本記事を読むと、分野別の頻出テーマと数字の押さえ方、暗記の優先順位、用語解説・過去問演習と組み合わせる週次ルーティンが分かります。

  • 4分野の頻出を表で整理
  • 業法数字は5営業日等をカード化
  • 用語解説＋過去問演習のループ
  • 目標は分野別正答
  • 直前は表と誤答

14分野の頻出テーマ一覧

頻出論点を分野別にリスト化し、数字は一問一答で固めると短期間で効率化できます。

| 分野 | 出題目安 | 頻出の中心 |
| --- | --- | --- |
| 宅建業法 | 20問 | 35条・37条・媒介・報酬・8種制限・保証金 |
| 権利関係 | 14問 | 抵当権・賃貸借・相続・登記 |
| 法令制限 | 8問 | 用途地域・建ぺい率・開発許可 |
| 税・その他 | 8問 | 固定資産税・登録免許税・統計（問46〜50） |

標準表は出発点であり、正本はご自身の過去問誤答リストです。他人のまとめをそのまま暗記するより、ミスした行だけ表に追記する運用が得点に直結します。模試で36〜38点以上を2回連続で、頻出の8割を取れる設計なら合格圏に届きやすくなります。

2業法で暗記すべき数字の例

業法は数字・期限のケアレスが失点の主因です。テーマごとにカード化し、条文番号とセットで覚えます。

| 数字・期限 | 関連テーマ |
| --- | --- |
| 5営業日 | 書面交付・レインズ登録など |
| 7営業日 | 手付金の保全など |
| 8日 | クーリングオフなど |
| 2週間 | 媒介契約・レインズ関連 |
| 3か月 | 媒介契約の有効期間など |
| 5年 | 免許の有効期間など |

法令制限・税の数字は別カードに分け、混同を防ぎます。通勤10分の一問一答に回し、まとまった時間は過去問の解説読みに使うとバランスが取れます。試験2週間前は新規章より、数字カードと35条チェックリストの毎日5分見返しを優先してください。

3分野別の優先順位と目標正答

満点より、出題数に見合った取れる点数を先に確保する設計が現実的です。

| 分野 | 目標正答 | 先に固める論点 |
| --- | --- | --- |
| 業法20問 | 14問以上 | 35条・37条・媒介・報酬 |
| 権利14問 | 8〜10問以上 | 抵当権・賃貸借・相続 |
| 法令8問 | 5〜6問以上 | 用途地域・建ぺい率 |
| 税8問 | 6問以上 | 頻出税目・統計の読み取り |

模試で35点未満が続く場合は、数字暗記より誤答論点の解き直しを優先します。頻出表は弱点補填用であり、過去問演習の代替にはなりません。2週間ごとに4分野別の正答数を記録し、最弱1分野に翌週+3時間追加する運用が続きやすいです。

4用語解説・過去問演習へのつなぎ方

  • サイトでは
  • 用語解説一覧で定義を確認し
  • 過去問演習で本番形式に慣れる導線が使え

| 曜日 | タスク例 |
| --- | --- |
| 週初め | 頻出表を見て、その週の過去問テーマを決める |
| 平日 | 数字カード10分＋過去問5問 |
| 週末 | 50問形式または分野別20問 |
| 誤答後 | 用語解説でキーワード2語を深掘り |

表で確認→過去問→誤答追加のループを回してください。動画学習の翌日は必ず過去問5問を解く習慣と組み合わせると、インプットだけで終わる失敗を防げます。知識ハブの数値・期限早見表と本記事を併用し、直前期は表と誤答ノートだけに絞る設計が安全です。

5直前期の使い方

試験2週間前は新しいテキストを開かず、頻出表と誤答ノートに集中します。

| 時期 | 毎日の目安 |
| --- | --- |
| 2週間前〜 | 数字5分＋過去問5問 |
| 1週間前〜 | 業法数字と35条チェック最優先 |
| 前日 | 表とカードのみ15分、新規問題は増やさない |

睡眠を削って暗記するより、誤答5問の解説読みの方が得点効率が高いことが多いです。50問模試は週1回までにし、復習量を増やします。2026年10月18日の試験日・4分野配分・受験料8,200円はRETIO要項で再確認し、古いまとめサイトの数字だけで学習を決めないでください。

6よくある質問

頻出論点はどこで一覧できますか？
本記事の分野別表と、知識ハブの数値・期限早見表、分野別対策ガイドを組み合わせてください。正本はご自身の過去問誤答リストであり、標準表に足りない項目を追記する運用が効果的です。他人のまとめをそのまま暗記するより、自分のミスに合わせて表を育てる方が得点に直結します。試験形式はRETIOの受験要項で確認してください。
数字暗記だけで合格できますか？
数字は業法・保証金で必須ですが、権利関係の理解・法令制限の計算は過去問演習が必要です。数字カード10分と過去問演習をセットにすると初めて得点になります。暗記だけ3週間より、過去問2周と数字カードの方がバランスが良い場合が多いです。用語解説で定義が曖昧な語だけ補強すると、似た問題での消去が速くなります。
直前1週間で何を優先しますか？
業法の数字・35条・37条のチェックリスト、誤答ノートの解き直しを最優先にしてください。新しい分野のインプットは止め、50問模試は週1回までにし、復習量を増やすのが安全です。頻出表は毎朝5分、論点は毎夜過去問5問が目安です。権利・法令は頻出表の該当行だけを読み、新しい論点の通読は控えめにしましょう。
