1速算式の型

報酬額は宅建業法で毎年1問以上、計算または上限判断で出題されます。

  • 売買・交換の速算式
  • 賃貸借の「1か月分以下」
  • 消費税の扱いが三大テーマ

公式を暗記したうえで、過去問の数字を使い「毎回同じ手順」で解くとミスが減ります。

  • ①取引種別を確認
  • ②課税価格を確認
  • ③速算式または上限を適用
  • ④消費税を加算
  • の4ステップを紙に書いてから計算してください

報酬は業法の得点源なので、週1回は計算ドリルだけを10分入れると安心感が増します。

2賃貸の報酬上限

売買・交換の速算式です。

・400万円以下：取引価格×4％＋固定額（最新条文で確認）
・400万円超4000万円以下：取引価格×3％＋固定額
・4000万円超1億円以下：取引価格×2％＋固定額
・1億円超：取引価格×1％＋固定額

境界400万円・4000万円・1億円の問題が頻出です。段階ごとに1問ずつ過去問を解き、計算結果を丸めないで途中式を残します。速算式の固定額部分はカードの表に太字で書き、毎朝見返すと抜けが減ります。

3消費税の扱い

賃貸借・その他の報酬です。

・賃貸：1か月分以下（礼金・保証金の扱いは問題文次第）
・交換・売買以外の取引形態：過去問パターンを蓄積
・消費税：報酬額に税を加算するか、税込み価格から逆算するかを問題文で確認
・広告料・割引と報酬上限の関係

賃貸は計算より「上限を超えるか」の判断問題が多いです。「2か月分」「1.5か月分」などの選択肢は、1か月分ルールで消去できます。

4練習の進め方

過去問演習と模試での時間配分です。

1. 報酬タグの問題を15問、計算機使用の有無を本番想定で解く
2. 間違えたのが式か数字か消費税かを分類
3. 媒介契約問題とセットの複合題を5問
4. 50問模試では報酬1問を3分以内
5. 直前は速算式カードと境界値例題だけ復習

計算問題は業法の中で確実に取るべき「得点源」です。権利関係で時間を使いすぎないよう、報酬は先に解く順番も検討してください。

5引っ掛け

よくある失敗と対策です。

  • 速算式の段階を取り違え → 価格を先に区切る
  • 消費税を二重計算 → 問題文の「税込み」「税抜き」を下線
  • 賃貸を売買の式で計算 → 取引種別を最初に書く
  • 端数処理を誤る → 過去問の正解肢の処理に合わせる

報酬と広告規制・利益提供禁止は別論点です。週1回は報酬計算ドリル10分だけを設定すると、本番の安心感が増します。

6よくある質問

報酬の速算式は暗記必須ですか？
はい。売買・交換の計算問題では速算式と境界値がそのまま出ます。カード化して毎日3問計算し、400万円・4000万円・1億円の境目は別色で強調してください。賃貸は「1か月分以下」の文言暗記が優先で、速算式より判断問題が中心です。
賃貸の報酬上限はどう覚えますか？
賃貸借の媒介報酬は原則1か月分以下です。過去問で「2か月分請求できる」などの誤答肢に慣れると、試験本番で消去しやすくなります。礼金・保証金を報酬に含めるかは問題文の設定に従い、条文の一般論と過去問の特例を分けてメモしてください。
計算問題は電卓を使いますか？
試験会場のルールは受験要項・当日案内で確認してください。手計算でも解けるよう、桁の大きい例題は週1回練習します。式を書いてから計算する習慣は、電卓あり・なし両方でケアレスミス防止になります。模試では本番と同じ道具で練習するのがおすすめです。
