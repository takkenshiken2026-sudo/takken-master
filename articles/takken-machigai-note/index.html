宅建の間違いノートの作り方｜復習で得点を伸ばす方法

過去問を何周するかより、1周目の誤答を2周目で潰せるかが得点に効きます。2026年度試験は10月18日（日）・50問・4分野・受験料8,200円（RETIO要項が正本）。本記事では間違いノートに書く4項目、知識不足・時間不足・ケアレスの3分類、1週間後の解き直し、紙とアプリの使い分け、形骸化しない運用ルールを表で整理します。問題番号のリストではなく「原因の記録」がノートの正体です。

この記事の要点

本記事を読むと、ノートに書く内容、3分類の付け方、1週間後の解き直しのやり方、ノートが機能しなくなる失敗と対処が分かります。

  • 4項目で記録
  • 3分類で対策を変える
  • 1週間後に解き直し
  • 2周目はノート中心
  • 直前は残行を減らす

1間違いノートに書く4項目

ノート1行は、次の4項目をセットで書きます。解説の長文コピーは避け、自分の言葉で1行に圧縮します。

| 項目 | 記入例 |
| --- | --- |
| 分野 | 業法・権利・法令・税 |
| 原因（3分類） | 知識不足／時間不足／ケアレス |
| キーワード | 35条・抵当権・用途地域など |
| 次回解き直し日 | 7日後の日付 |

過去問を始めた最初の週から運用を始めてください。

  • 後からまとめると
  • 解説の印象が薄れ
  • 原因分類が不正確になり

テキスト章末の誤答も同じ形式で記録すると、本番年のノートが一冊にまとまります。2週間ごとに残り行数を記録し、減っていなければ解き直し量を見直します。

2知識不足・時間不足・ケアレスの3分類

同じ誤答でも、次の対策が変わります。分類を間違えると復習が空回りします。

| 分類 | 典型例 | 次の1週間の対策 |
| --- | --- | --- |
| 知識不足 | 条文・用語が出てこない | 用語解説→同タグ10問 |
| 時間不足 | 後半を適当に選んだ | 50問90分を週1回 |
| ケアレス | 読み違え・消し忘れ | 解き直し＋時間配分メモ |

3分類のうちどれが多いかで、週の配分を調整します。

  • 知識不足が多いなら業法か権利の頻出から
  • 時間不足なら本番形式の計測
  • ケアレスなら解き直しの質を上げ

4分野別の正答数を2週間ごとに記録し、最弱1分野にだけ+3時間追加する運用が続きやすいです。模試目標は36〜38点以上を2回連続です。

31週間後の解き直しサイクル

基本サイクルは「解く→記録→1週間後に解き直し→正解したら消す」です。

| 周 | 新規過去問 | ノート |
| --- | --- | --- |
| 1周目 | 分野別に解く | 全誤答を4項目で記録 |
| 2周目 | 週10問までに制限 | ノートの行だけ解く |
| 3周目 | 50問模試中心 | 残行＋模試の誤答追加 |

解き直しで再び誤ったら、原因欄を上書きし2週間後に再スケジュールします。3回連続で落ちる論点は、テキスト該当章を10ページだけ読み直します。試験1か月前はノート残行が減るまで新規インプットを止め、誤答と数字カードに集中するのが効率的です。約40％の誤答を1週間後に再挑戦する量が現実的です。

4紙とアプリの使い分け

ツールより、原因の1行メモと1週間後の解き直しを守ることが重要です。

| 媒体 | 向く用途 | 注意 |
| --- | --- | --- |
| 紙 | 直前総復習・付箋強調 | 検索は遅い |
| アプリ | 通勤見直し・検索 | 転記ルールが必要 |
| 併用 | 週末に誤答を紙へ集約 | 途中で媒体を変えない |

アプリで誤答フラグをつけたら、週末に4項目を紙へ転記するルールを決めます。本番2週間前は紙1冊に誤答を集約し、会場持ち込み用の最終チェックにすると安心です。50問本番形式は紙またはPCで90分計測し、スマホは一問一答と用語確認に使う二段構えが向きます。

5形骸化しない運用と直前の重点

ノートが機能しない典型と対処です。

| 失敗 | 対処 |
| --- | --- |
| 問題番号だけ | 原因・キーワードを必ず1行 |
| 解き直ししない | 週末30分をノート専用に固定 |
| 正解行を消さない | 3回正解で削除 |
| 解説長文コピー | 自分の言葉に圧縮 |
| 分野別記録なし | 2週間ごとに4分野正答数 |

残り50行以下になったら、模試で36点以上を目指す段階に入れます。2026年10月18日試験・受験料8,200円はRETIO要項で再確認し、直前2週間は新規章よりノートと業法数字の毎朝5分見返しを優先してください。正解理由と誤り肢の理由を説明できるかが、得点伸びの指標になります。

6よくある質問

間違いノートはいつから作ればよいですか？
過去問を始めた最初の週から作ってください。1周目の誤答は復習の核なので、解いた当日に4項目を書きます。後からまとめると原因の分類が不正確になります。テキスト通読中でも、章末問題の誤答は同じ形式で記録しておくとスムーズです。週末30分をノート解き直し専用にカレンダー固定すると続きやすくなります。
ノートが増えすぎたらどうしますか？
解き直しで3回正解した行は削除し、2回目でまだ誤る行だけ残します。試験1か月前は、直近2年分の誤答に絞ってノートを作り直す方法もあります。新規問題を増やすより、残った行をゼロにすることを優先してください。3分類のうちケアレスが多い場合は、50問90分の計測回数を増やすと効果が出やすいです。
紙とアプリ、どちらがよいですか？
通勤見直しが多い人はアプリ、直前に一冊で総復習したい人は紙が向きます。重要なのは媒体より、原因の1行メモと1週間後の解き直しを守ることです。アプリ利用者は週末に誤答を紙へ転記する日を月1回入れると定着しやすくなります。試験形式・日程はRETIOの受験要項で確認してください。
