12種類の保証金

営業保証金・弁済業務保証金・宅建業保証協会は、宅建業法の数字問題として安定して出題されます。

  • 2種類の保証金の目的の違い
  • 供託か協会加入かの選択
  • 弁済の順序を表とフロー図にまとめると短期で得点でき

実務の手続詳細より、試験で繰り返される金額・割合・「どちらが先に弁済されるか」が中心です。業法の中では報酬・媒介と同列の「確実に取りたい1問」として週1回復習を入れましょう。

2供託と分担金

2種類の保証金の違いです。

・営業保証金：主店移転等に伴う供託、取引業者への弁済のための供託
・弁済業務保証金：弁済業務委託者（買主等）への弁済
・供託額：本店・支店・免許更新等で異なる（数字は過去問と条文で確認）
・保証協会：加入により営業保証金の供託を置き換える制度

「誰のためにある保証金か」を左列に書いた表が、事例問題の読み解きに直結します。供託先・提出先の違いも過去問で確認し、手続問題と数字問題を分けて記録しましょう。

3充当金2週間

保証協会・分担金・弁済順序です。

・加入：営業保証金の供託に代わる（要件・手続は過去問で確認）
・分担金：会員が負担、弁済財源の一部
・弁済順序：営業保証金→保証協会の弁済→社債等（問題文の設定に注意）
・免許取消・廃業時の供託・返還

フロー図はA4縦1枚に収め、矢印で「先にどこから弁済するか」を示します。順序違いの選択肢は毎年の定番です。保証協会の分担金と弁済の関係は、過去問の正解解説をそのままフローに転記すると覚えやすいです。

4保証協会

過去問演習です。

1. 保証金・保証協会タグ15問
2. 数字だけの問題と手続問題を分類
3. 本店移転・支店設置・更新の3パターンを表に追記
4. 報酬・媒介と混同したら業法ノートを統合
5. 直前は数字カード＋フロー図のみ毎日5分

  • 暗記が中心なので
  • 2周目は解く時間を短縮し
  • 1問2分以内を目標にすると本番の時間余裕につながり

直前1週間は新規演習より、保証金タグの誤答解き直しを優先してください。

5暗記のコツ

よくある失敗と対策です。

  • 2種類の保証金を混同 → 目的と請求権者で分ける
  • 供託と協会加入を逆 → 「供託省略の条件」を過去問で確認
  • 弁済順序を感覚で選ぶ → フロー図を必ず見る
  • 数字をバラバラ暗記 → 本店・支店・更新の3列表にまとめる

業法20問で12問狙いの場合、保証金は「落とさない1問」として35条・媒介・報酬と同じ優先度で直前2週間を設定してください。

6よくある質問

営業保証金と弁済業務保証金の違いは？
営業保証金は取引業者等への弁済、弁済業務保証金は弁済業務委託者への弁済が目的です。誰が請求権者か、どの取引段階かが問題文のキーワードになります。比較表を作り、過去問10問で「誰に対する保証か」を線引きする練習をしてください。
保証協会に加入すると供託は不要ですか？
加入により営業保証金の供託が置き換わる制度ですが、要件・手続・分担金は過去問と条文で確認が必要です。「完全に不要」と一概には言えない設問もあるため、供託額の数字問題とセットで学習すると安全です。本店移転時の特例も過去問で繰り返し出ます。
保証金問題は何問くらい出ますか？
毎年1問前後が目安で、数字と手続・弁済順序が交互に出ます。15問を2周すれば安定得点しやすい分野です。他の業法論点と比べ暗記比重が高いので、直前1か月は毎日5分のカード見直しが効率的です。報酬・媒介と同じ週に復習すると、業法の数字問題をまとめて固められます。
