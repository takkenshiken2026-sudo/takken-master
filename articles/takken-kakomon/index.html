宅建の過去問の使い方・効果的な解き方を解説

過去問は宅建合格の核ですが、「解くだけ」では伸びにくい分野もあります。2026年度は10月18日（日）試験・50問・4分野・受験料8,200円（RETIO要項が正本）。本記事では直近5年分の回し方、テキスト先行後の切替、誤答の40％を1週間後に解き直すサイクル、解説で根拠を1行メモする方法を表で整理します。模試目標は36〜38点以上を2回連続で、記録は4分野別に分けてください。

この記事の要点

本記事を読むと、過去問の推奨年数と周回、テキストと過去問の順序、解き直し40％の運用、50問90分への落とし込み方が分かります。

  • 直近5年分が目安
  • テキスト先行後に過去問比重UP
  • 誤答40％を1週間後に再挑戦
  • 4分野別記録
  • 50問90分を月2回以上

1なぜ過去問が宅建の中心教材か

出題パターンは年次で大きく変わらないため、「何が問われるか」を過去問から逆算できます。

| 効果 | 内容 |
| --- | --- |
| 論点の絞り込み | 頻出に集中し、非頻出の追い込みを減らす |
| 本番形式 | 50問90分・4分野の配分に慣れる |
| 弱点の可視化 | 4分野別正答数で次週の時間を決める |

テキストだけで終わらせず、通読の8割が終わった時点で過去問比率を上げると得点が伸びやすくなります。

  • 解いた直後は正誤より
  • 解説で「なぜ正解か・なぜ他肢が誤りか」を1行メモすることが
  • 2周目以降の伸びに直結し

合格圏は模試で36〜38点以上を2回連続で、手続き数字は要項で再確認してください。

2何年分・何周するか（5年分が目安）

直近5年分（250問相当）を軸に、解き直し込みで実質2周が目安です。

| 段階 | 目標 |
| --- | --- |
| 1周目 | 解説読み・4分野別に誤答記録 |
| 2周目 | 誤答＋ケアレスのみ解き直し |
| 直前 | 直近2年分を50問90分で週1〜2回 |

5年より古い問題は、制度改正の影響を受けやすいため解説の改訂年を確認します。

  • 初学者なら15〜20問
  • 直前2か月は30問以上を目安にし
  • 新しい問題集を増やすより既存誤答の解き直しを優先してください

総学習時間300時間前後のうち、過去問演習に120時間程度を割く設計がバランス良いです。

3テキスト先行と過去問への切替

インプットと過去問の比率は時期で変えます。テキスト先行が基本です。

| 残り期間 | テキスト | 過去問・復習 |
| --- | --- | --- |
| 6〜4か月前 | 60％ | 40％ |
| 3〜2か月前 | 30％ | 70％ |
| 1か月前 | 10％ | 90％ |

「テキストが終わっていない」不安があっても、頻出の8割を過去問で取れる設計に切り替えると得点が伸びることが多いです。宅建業法・権利関係はテキストで用語を押さえたら、すぐ分野別過去問10問/週に入れてください。試験2か月前から新しい参考書は止め、誤答ノートと50問形式に集中します。

4解き直し40％と解説の読み方

1周目の誤答のうち、翌週解き直すのはおおむね40％が現実的な量です（全部だと時間不足になりやすい）。

| 記録項目 | 書く内容 |
| --- | --- |
| 分野 | 業法・権利・法令・税 |
| 原因 | 知識不足・読み違え・ケアレス |
| 根拠 | 解説の1行メモ（条文名・キーワード） |
| 再挑戦日 | 1週間後のカレンダー登録 |

3回連続正解した行はノートから削除し、2回目でまだ誤る行だけ残します。

  • 解説は「正解肢だけ読む」で終わらせず
  • 誤り肢がなぜ誤りかを声に出すレベルまで確認すると
  • 似た問題で消去が速くなり

4分野別の正答数を2週間ごとに見直し、最弱1分野に翌週+3時間追加する運用が続きやすいです。

550問90分への落とし込み

過去問演習は、最終的に50問90分の塊で計測します。

| 時期 | 頻度 |
| --- | --- |
| 試験3か月前〜 | 月2回以上 |
| 試験1か月前〜 | 週1〜2回 |

時間配分の目安は業法35分・権利25分・法令15分・税15分です。1問90秒を超えたらマークし、最後の10〜15分で見直します。

模試と過去問の役割分担。

  • 過去問が論点習得
  • 外部模試が本番形式の最終確認

36点未満が続く場合は周回数を増やすより、誤答解き直しの質を上げる方が効くことが多いです。

6よくある質問

過去問は何年分解けばよいですか？
直近5年分を軸に、解き直し込みで2周が目安です。5年より古い問題は制度改正の影響を受けやすいため、解説の改訂年を必ず確認してください。週15〜20問から始め、直前2か月は30問以上に増やす設計が現実的です。総時間300時間前後なら過去問に120時間程度を割ると、4分野のバランスが取りやすくなります。
解き直しは全部やるべきですか？
全部ではなく、1周目誤答の約40％を1週間後に再挑戦する量が現実的です。3回連続正解した問題はノートから外し、2回目も誤る問題だけ残します。試験1か月前は直近2年分の誤答に絞り直す方法も有効です。新規問題を増やすより、残った行をゼロにすることを優先してください。
過去問と模試の違いは？
過去問は論点習得と解説読みが主目的、模試は時間配分と本番形式の慣れが主目的です。過去問を2周したら、50問90分のセットを自宅模試として扱い、外部模試は弱点の最終確認に使うと役割がはっきりします。どちらも解説読みと誤答記録がセットである点は同じです。目標は36〜38点以上を安定させることです。
