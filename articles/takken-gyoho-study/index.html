宅建業法の勉強法・完全攻略

宅建業法は50問中20問（40％）を占め、得点の柱になる分野です。暗記と過去問の型が効き、目標は14問以上・模試全体で36〜38点以上を2回連続です。2026年度は10月18日（日）試験・受験料8,200円（RETIO要項が正本）。本記事では35条・37条を中心とした頻出順、数字のカード化、週4時間の業法配分を表で整理します。テキスト1周後は過去問比重を上げ、新しい参考書は試験2か月前に止めてください。

この記事の要点

本記事を読むと、業法20問で35条・37条をいつ固めるか、数字暗記のカードの作り方、目標14問以上の過去問量と週次スケジュールが分かります。

  • 20問で目標14問以上
  • 35条・37条を最優先
  • 数字はカード＋過去問
  • 週4時間・過去問40％
  • 直前は誤答解き直し

1宅建業法20問の位置づけと目標

業法は出題比率が最も高く、週次計画では最初に時間を確保する分野です。

| 項目 | 内容 |
| --- | --- |
| 出題数 | 20問（50問の40％） |
| 目標正答 | 14問以上 |
| 週の目安 | 4時間（過去問2時間含む） |
| 合格の目安 | 模試全体36〜38点以上×2回 |

35条重要事項説明・37条書面・報酬・媒介契約・8種制限などが頻出です。条文丸暗記より「誰が・いつ・何を・どう交付するか」の型で覚えると安定します。

  • 業法だけ14問以上でも他分野が足りず総合点が届かないため
  • 4分野別の正答数を2週間ごとに記録し
  • 最弱分野にだけ+3時間振る運用にしてください

235条・37条を先に固める

業法20問のうち、35条・37条関連だけで毎年数問が出る年が多いです。

| 条文 | 試験の焦点 |
| --- | --- |
| 35条 | 説明のタイミング・記載事項・口頭と書面 |
| 37条 | 37条書面の交付・契約書面の交付 |

比較表を1枚作り、過去問で「成立後に初めて説明」など時期違いの誤答肢に慣れます。5営業日・2週間など関連数字は別カードに分け、媒介契約の数字と混同しないよう整理してください。IT重説の要点は要項・解説で確認し、試験2週間前はチェックリストだけを毎日5分見返すとケアレスが減ります。

3報酬・媒介・8種制限の順番

35条・37条の次に、報酬・媒介契約・8種制限を表で横並びにします。

| テーマ | 学習のコツ |
| --- | --- |
| 報酬 | 速算式・賃貸1か月分以下をカード化 |
| 媒介契約 | 一般・専任・専属の比較表 |
| 8種制限 | 適用取引かどうかを図示 |

業法の週配分では、35条週・37条週・報酬週のようにテーマを固定すると続きやすいです。過去問は分野別10問/週から始め、試験3か月前から50問のうち業法20問だけを90分の一部（35分）で解く練習に入れます。数字問題は毎日3問計算する10分ドリルが、本番の安心感につながります。

4数字暗記と過去問演習

業法は数字・期限のケアレスが失点の主因です。

| 種類 | 例 |
| --- | --- |
| 期限 | 5営業日・7営業日・2週間・3か月 |
| 金額 | 手付金・保証金・報酬上限 |
| 割合 | 速算式の境界値 |

暗記カードは通勤10分で回し、まとまった時間は過去問解説読みに使います。1問解いたら誤答理由を4分野ノートの業法欄に書き、1週間後に解き直します。2周目は誤答とケアレスのみに絞り、新しい問題集は増やさない方が14問ラインに届きやすいです。業法と過去問に週の40％（4時間中2時間）を割る設計が、多くの合格者の配分に近いです。

5直前と他分野とのバランス

直前1か月は業法の数字・35条チェックリストと誤答解き直しが最優先です。

| 優先 | 非優先 |
| --- | --- |
| 35条・37条・報酬の誤答 | 未読の業法の末章 |
| 50問90分の時間計測 | 新しい業法テキスト |

業法14問以上を取りつつ、権利8問・法令5問・税6問で36〜38点を狙うバランス表を自分用に作ってください。業法に偏りすぎて権利が6問以下が続く場合は、週1時間だけ権利の頻出過去問に戻します。試験日10月18日・開始13:00は要項で再確認し、受験票・会場・持ち物は直前ガイドと合わせてチェックしてください。RETIO要項が手続きと出題の正本です。

6よくある質問

宅建業法は何問出ますか？
50問中20問です。出題比率が最も高いため、週次計画では業法に4時間前後を先に確保するのが基本です。目標は14問以上で、35条・37条・報酬・媒介を中心に過去問を回します。全体の合格圏は模試で36〜38点以上を2回連続で、4分野別に正答数を記録しながら調整してください。
35条と37条、何から勉強すべきですか？
35条（重要事項説明）と37条（書面交付）の違いを比較表で押さえ、過去問5問で混同パターンに慣れるのが近道です。説明のタイミング・記載事項・主体が試験の焦点です。関連数字は媒介契約のカードと分け、試験2週間前はチェックリストだけを毎日見返すと効率的です。IT重説は要項・最新解説で要点を確認してください。
業法で14問未満のときはどうしますか？
翌週だけ業法に+2時間追加し、35条・37条・報酬の誤答20問の解き直しに集中します。新規テキストは止め、頻出の比較表と数字カードを毎日10分見返してください。2週間後に同じ50問の業法ブロックで正答が+2問以上なら調整成功と判断できます。それでも伸びない場合は、解説を声に出すレベルまで読む質の見直しが先です。
