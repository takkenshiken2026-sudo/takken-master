1法令上の制限が伸ばしやすい理由

法令上の制限は50問中8問（16％）。都市計画法・建築基準法を中心に、国土利用計画法・農地法・宅地造成等規制法なども出題されます。

制度名と数字が多い分野ですが、出題範囲は比較的整理しやすいです。目標は8問中6問以上（75％）。表で違いを押さえると、短期間で得点を上げやすくなります。都市計画法と建築基準法に全体の7割の時間を配分するのが、初学者向けの標準的な進め方です。

2優先順位

優先度の高い論点です。

1. 用途地域（13種類）と建築可能な建物
2. 建ぺい率・容積率・セットバック
3. 開発許可・届出（規模・要件）
4. 建築確認・検査
5. 農地転用・宅地造成規制

まず用途地域の表を1枚作成し、毎日5分見返します。次に建ぺい率・容積率の計算パターンを過去問5問で確認します。農地法・宅地造成規制法は、過去問に出た論点だけ後から追加すれば足りることが多いです。

3都市計画法・建築基準法

表整理の例です。

用途地域表：地域名｜建築制限の要点｜典型問題のキーワード
建ぺい率・容積率：角地・防火地域・準防火地域の加算ルール
許可・届出：面積・戸数の閾値｜誰が申請するか

暗記は「一覧表→過去問→誤答修正→表に追記」の循環が効率的です。手書きの表1枚を試験直前まで更新し続けると、本番でも思い出しやすくなります。表の横に過去問番号を書いておくと、復習時にすぐ問題へ戻れます。

4数字暗記のコツ

過去問演習の進め方（法令制限8問）です。

1. 直近5年分から法令制限問題を抽出（約40問）
2. 用途地域・建ぺい率・許可制度の3分類
3. 各分類10問ずつ、正答率70％を目標
4. 数字問題は計算手順を1行メモ
5. 50問模試では法令8問を15分以内

「なんとなく覚えた」状態は解き直しで必ず確認します。正答率70％未満の分類だけ、解説を読み直して表に追記してください。

51週間の学習ルーティン

つまずきと対策です。

  • 法律名が多すぎて混乱 → 都市計画・建築基準の2法に7割の時間
  • 数字を丸暗記 → 過去問の選択肢とセットで覚える
  • 計算を避ける → 建ぺい率・容積率は5問だけ反復
  • 直前に全法律を読む → 表と誤答ノートだけ見直す

法令制限は直前2週間の確認でも点数が伸びやすい分野です。用途地域の表と建ぺい率の計算だけは、試験前日にも15分確認してください。

6よくある質問

法令上の制限は何問出ますか？
50問中8問です。出題数は少ないですが、表で整理すれば6問以上を安定して取れる分野です。用途地域・建ぺい率・容積率を優先し、過去問40問程度を2周すると得点源になります。都市計画法と建築基準法に学習時間の7割を配分するのがおすすめです。
用途地域は全部覚える必要がありますか？
13種類すべての名称と、主要な建築制限の違いを表で押さえる必要があります。ただし細部の例外まで最初から完璧にする必要はなく、過去問で出たパターンから優先的に暗記を追加していけば十分です。一種低層住居専用地域と低層住居専用地域の違いなど、紛らわしいペアは表で並べて覚えます。
建ぺい率・容積率の計算は出ますか？
計算形式の問題が出ることがあります。角地・防火地域などの加算ルールを表にまとめ、過去問5問を解説付きで反復してください。計算手順を1行メモに残すと、似た問題でミスが減ります。防火地域・準防火地域の加算有無は、過去問で最も出やすいパターンから覚えてください。
