宅地建物取引士試験 過去問 2013年 第9問（権利関係）

Aに雇用されているBが、勤務中にA所有の乗用車を運転し、営業活動のため顧客Cを同乗させている途中で、Dが運転していたD所有の乗用車と正面衝突した(なお、事故についてはBとDに過失がある。)場合における以下の記述のうち、民法の規定と判例に照らすと、正しいものを選びなさい。

問題

Aに雇用されているBが、勤務中にA所有の乗用車を運転し、営業活動のため顧客Cを同乗させている途中で、Dが運転していたD所有の乗用車と正面衝突した(なお、事故についてはBとDに過失がある。)場合における以下の記述のうち、民法の規定と判例に照らすと、正しいものを選びなさい。

選択肢

  1. （1） Aは、Cに対して事故によって受けたCの損害の全額を賠償した。このとき、Aは、Bと Dの過失割合に従って、Dに対して求償権を行使できる。
  2. （2） Aは、Dに対して事故によって受けたDの損害の全額を賠償した。このとき、Aは、被用者であるBに対して求償権を行使できない。
  3. （3） 事故によって損害を受けたCは、AとBに対して損害賠償を請求できるが、Dに対して損害賠償を請求できない。
  4. （4） 事故によって損害を受けたDは、Aに対して損害賠償を請求できるが、Bに対して損害賠償を請求できない。

正答

正答は （1） です。

解説

正解は選択肢1です。

正解の理由

正解は選択肢1です。 選択肢1の「Aは、Cに対して事故によって受けたCの損害の全額を賠償した。

（1） Aは、Cに対して事故によって受けたCの損害の全額を賠償した。このとき、Aは、Bと Dの過失割合に従って、Dに対して求償権を行使できる。

他の選択肢

  • （2） Aは、Dに対して事故によって受けたDの損害の全額を賠償した。このとき、Aは、被用者であるBに対して求償権を行使できない。

    （2）「Aは、Dに対して事故によって受けたDの損害の全額を賠償した。このとき、Aは、被用者であるBに対して求償権を行使できない。」は、作業主任者の選任が必要な作業の組合せ（ACCABDD）を含んでいません。解説のとおり、該当作業と非該当作業の区別を確認してください。 （2）「Aは、Dに対して事故によって受けたDの損害の全額を賠償した。このとき、Aは、被用者であるBに対し…」について：他の選択肢は、主体・手続・期間・効果などの点でずれています。

  • （3） 事故によって損害を受けたCは、AとBに対して損害賠償を請求できるが、Dに対して損害賠償を請求できない。

    （3）「事故によって損害を受けたCは、AとBに対して損害賠償を請求できるが、Dに対して損害賠償を請求でき…」について：他の選択肢は、主体・手続・期間・効果などの点でずれています。

  • （4） 事故によって損害を受けたDは、Aに対して損害賠償を請求できるが、Bに対して損害賠償を請求できない。

    （4）「事故によって損害を受けたDは、Aに対して損害賠償を請求できるが、Bに対して損害賠償を請求できない…」について：他の選択肢は、主体・手続・期間・効果などの点でずれています。
