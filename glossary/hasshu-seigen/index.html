宅建業法

8種制限とは？自ら売主制限を一覧でわかりやすく解説【宅建】

（はっしゅせいげん）

8種制限とは、宅建業者が自ら売主となり買主が宅建業者でない一般消費者の場合に適用される8つの消費者保護規定です。クーリングオフ・手付金の上限・損害賠償予定額の制限など、いずれも「業者に不利・消費者に有利」な強行規定で、違反する特約は無効となります。宅建試験では毎年出題される最重要テーマです。

8種制限とは

宅建業者が自ら売主となり、買主が宅建業者以外（一般消費者）の場合に適用される8つの特別規制。①クーリングオフ ②損害賠償予定額の制限 ③手付金等の保全措置 ④手付の額の制限 ⑤担保責任についての特約の制限 ⑥割賦販売契約の解除等の制限 ⑦所有権留保等の禁止 ⑧他人物売買の制限（宅建業法39〜43条）

適用条件の確認：「宅建業者が自ら売主」かつ「買主が宅建業者でない」場合のみ適用。売主・買主ともに宅建業者の場合（業者間取引）は適用されません。宅建業者が媒介・代理をするだけの場合も適用されません。

8種制限 一覧表

制限の種類内容・数字根拠条文
①クーリングオフ 事務所等以外での申込み・契約は、書面による告知を受けた日から8日以内に書面で解除できる。解除後は全額返還（損害賠償・違約金の請求不可） 37条の2
②損害賠償予定額の制限 損害賠償の予定額と違約金の合計が代金の20%超の特約は無効。20%を超える部分が無効となり20%に引き下げられる 38条
③手付金等の保全措置 未完成物件：代金の5%超または1,000万円超の手付金等を受領する前に保全措置が必要。完成物件：10%超または1,000万円超 41条・41条の2
④手付の額の制限 手付金の額は代金の20%以内。それを超える部分の特約は無効（20%に引き下げ）。手付は解約手付として機能（相手方履行着手前まで解除可） 39条
⑤担保責任の特約の制限 契約不適合責任について買主に不利な特約は無効。ただし「引渡しから2年以上」とする特約は有効（民法の規定より長ければ有効） 40条
⑥割賦販売契約の解除等の制限 割賦販売で買主が賦払金の支払いを怠った場合、30日以上の相当期間を定めて催告し、それでも不払いの場合でなければ契約解除や残代金の一括請求ができない 42条
⑦所有権留保等の禁止 引渡し後は原則として所有権留保禁止。ただし代金の10分の3超を受領するまでは所有権を留保できる（または保全措置を講じた場合） 43条
⑧他人物売買の制限 自ら所有していない物件（他人物・未完成物件）について、将来確実に取得できる見込みがある場合を除き、売買契約を締結することは禁止 33条の2

必ず覚える数字まとめ

  • 120%：手付金の上限・損害賠償予定額の上限（いずれも代金の20%）
  • 28日以内：クーリングオフの行使期間（告知を受けた日から8日）
  • 3未完成5%超 / 完成10%超：手付金等の保全措置が必要になる金額の基準
  • 42年以上：担保責任特約で有効とされる最短期間（引渡しから2年以上）
  • 530日以上：割賦販売で解除前に必要な催告期間
  • 610分の3超：所有権留保が禁止される代金受領割合の基準

特約の有効・無効の考え方

8種制限はすべて「買主保護」のための強行規定です。

買主に不利な特約 → 無効
例：「損害賠償予定額を代金の30%とする」→ 20%を超える部分が無効となり20%になる

買主に有利な特約 → 有効
例：「損害賠償予定額を代金の10%とする」→ 買主有利なので有効

担保責任の特約の注意点：「引渡しから1年以内に通知」という特約は民法の原則（知った時から1年）より短く買主に不利なため無効。「引渡しから2年以上」なら有効。

練習問題

CHECK QUIZ

宅建業者Aが自ら売主となり、宅建業者でないBとの間で宅地の売買契約を締結する場合に関する記述として、宅建業法の規定によれば正しいものはどれか。

  1. 1. 損害賠償の予定額を代金の30%と定める特約は有効である。
  2. 2. 手付金の額を代金の20%以下とする特約は有効であるが、20%を超える部分は無効となる。
  3. 3. 売主Aが履行に着手していれば、買主Bはクーリングオフによる契約解除ができない。
  4. 4. Aが保全措置を講じた場合でも、未完成物件について代金の5%を超える手付金を受領することはできない。
正解：2
手付金の上限は代金の20%で、超過部分の特約は無効となります（宅建業法39条）。
1は誤り：損害賠償予定額は代金の20%が上限。30%の特約は20%を超える部分が無効となり20%になります（38条）。3は誤り：クーリングオフは「相手方（買主B）が申込みの撤回等を行うことができなくなるまで」の期間に関係し、売主Aの履行着手は関係ありません。4は誤り：保全措置を講じれば5%超の手付金受領が可能になります（41条）。

よくある質問

Q宅建業者同士の取引に8種制限は適用されますか？
適用されません。8種制限は「売主が宅建業者・買主が宅建業者でない」場合のみ適用されます。売主・買主ともに宅建業者の業者間取引では8種制限は適用されず、当事者が自由に特約を定めることができます。
Qクーリングオフはどんな場所での契約でも使えますか？
使えない場所もあります。宅建業者の事務所・案内所（届出済み）・買主が自ら申し出た自宅・勤務先での契約はクーリングオフができません。喫茶店・ホテルのロビーなど「事務所等以外」の場所での契約が対象です。また物件の引渡しを受けかつ代金の全額を支払った後はクーリングオフできません。
Q手付解除と8種制限の手付の違いは？
8種制限の手付規制は「手付金の上限を代金の20%にする」ことと「手付を解約手付として機能させる」ことの2点です。手付解除（買主は手付放棄、売主は手付倍返し）は相手方が「履行に着手するまで」の間のみ行使できます。宅建業者が売主の場合、この手付解除に関する規定より買主に不利な特約は無効です（宅建業法39条2項）。
