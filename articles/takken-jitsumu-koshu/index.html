1合格後の流れ

宅建試験の合格は、宅地建物取引士になるための通過点です。

  • その後は①合格証明の取得
  • ②登録実務講習の受講
  • ③宅建士登録申請
  • ④所属宅建業者への届出
  • という順で手続きが進み

合格証明には有効期限があり、期限を過ぎると講習受講の前提が失われます。合格発表直後に日程表を作り、講習の予約枠が埋まる前に申込むのが鉄則です。手続きは公益財団法人 不動産適正取引推進機構および所属先の人事・総務と連携します。

2登録実務講習

登録実務講習の概要です。

・目的：宅建業の実務・倫理・法令遵守の確認（試験範囲の再試験ではない）
・形式：集中講義が一般的（オンライン・会場は年度・主催により異なる）
・費用：受講料は機関・日程で変動（数万円前後が目安）
・内容：35条・37条・広告・保証金など実務寄りのケース

講習では演習とレポートがあり、欠席・未提出は修了に影響します。試験勉強のノートを持参すると、条文の実務イメージがつながりやすくなります。

3宅建士登録

宅建士登録申請の流れです。

1. 講習修了証明の取得
2. 登録免許税の納付（金額は年度要項で確認）
3. 登録申請書・証明写真等の提出
4. 国土交通大臣への登録、宅建士証の交付

登録後は5年ごとの更新講習が必要です。

  • 専任宅建士として事務所に置かれる場合
  • 所属法人が届出を行い
  • 署名・押印などの権限が与えられ

未所属のまま登録だけ完了することも可能ですが、実務は別途雇用が必要です。

4費用の目安

費用とスケジュールの立て方です。

  • 合格後にかかる主な費用：登録実務講習受講料
  • 登録免許税
  • 証票交付手数料

受験時の受験料・教材費に上乗せされるため、合格前に総額見積もりをしておくと安心です。

社会人は有給を講習日に合わせ、学生は就活と並行しない週を確保します。合格証明の期限が短い年度は、旅行や転職の予定より講習を最優先に入れてください。費用は受験料とは別枠で貯金しておくと、合格直後の手続きがスムーズです。

5関連ガイド

よくあるトラブルと対策です。

  • 講習枠が満席 → 合格直後に複数日程を候補登録
  • 期限切れ → やむを得ず再受験が必要になる場合あり（要項確認）
  • 所属先未決定 → 登録は可能だが専任として働くには雇用が必要
  • 5問免除者の手続 → 一般受験者と講習・登録の要否が異なる場合あり

手続きの正本は常にRETIOの最新案内です。本記事の整理は学習カレンダー用であり、金額・期限は申込前に必ず公式で再確認してください。講習前に業法過去問10問を解くと、講義の理解度が上がりやすいです。

6よくある質問

合格後、登録実務講習はいつまでに受けますか？
合格証明に記載された有効期限内に受講・修了する必要があります。期限は年度・個人の合格回によって異なるため、合格通知と同時に公式案内で確認してください。人気日程は早く埋まるため、合格発表週に申込完了を目標にすると安全です。期限ぎりぎりは再受験リスクもあるため避けましょう。
講習を受けなくても宅建士になれますか？
原則、登録実務講習の修了が登録申請の要件です。5問免除など特例がある場合は受験要項・合格後案内で確認が必要です。講習は試験より短い期間ですが、出席・課題提出が修了条件になるため、旅行や転職活動と重ねないスケジュール設計が重要です。
登録までにかかる費用はどれくらいですか？
講習受講料、登録免許税、証票手数料を合わせると、おおむね数万円〜十数万円規模になることが多いです。金額は年度・講習会場で変わるため、合格直後にRETIOと講習主催者の案内で一覧化してください。受験料・教材費と合わせた総コストで、転職・手当の期待値と比較すると計画が立てやすくなります。
