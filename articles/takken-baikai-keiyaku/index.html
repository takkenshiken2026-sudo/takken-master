13種類の一覧

媒介契約は宅建業法の頻出テーマで、毎年2〜3問程度出題されます。一般媒介・専任媒介・専属専任媒介の3種類を、レインズ登録義務・有効期間・報酬・他社成約時の取扱いで比較表にまとめるのが最短ルートです。

条文の細部より、過去問で繰り返し出る数字（5営業日・7営業日・2週間・3か月）を契約種類ごとに紐づけて暗記します。図で「依頼者―宅建業者―第三者買主」の関係を描くと、専属の「専属」意味が理解しやすくなります。

2レインズ登録

3種類の違い（試験向け要点）です。

- ・一般媒介：複数業者に依頼可
- レインズ登録義務なし（要件確認）
・専任媒介：依頼は1社
- レインズ登録義務あり
- 期間・報酬の規定
・専属専任媒介：依頼1社＋専属性
- 登録・報酬・他社成約時の規定が最も厳しい

「登録の有無」「依頼先の数」「他社が成約したときの報酬」は必ず3列で比較してください。試験では1項目だけ違う選択肢が多く、表の1行ずつ確認する癖が必要です。

3報告義務

数字と手続の暗記です。

  • 契約書面交付：5営業日以内（媒介契約成立後）
  • 手付金等：7営業日（関連問題とセット）
  • レインズ登録：2週間以内（専任・専属で義務）
  • 有効期間：3か月（延長含む、条文で確認）

数字は一問一答アプリで毎日10分。媒介契約の種類名を口頭で言いながら数字を答えると、事例問題でも思い出しやすくなります。延長・解除の要件は過去問の解説で拾い、表の脚注に追記しておくと直前復習が楽です。

4終了・更新

過去問演習です。

1. 媒介契約タグ20問を年度順に解く
2. 正解肢から「種類＋数字＋報酬」を抽出
3. 誤答は「登録」「期間」「報酬」のどれか分類
4. 35条・37条問題と混同したらタイミング表を追加
5. 1週間後に誤答のみ再試行

専属専任は「依頼者が他社と直接契約しても報酬」など例外が試験向きです。例外だけを別ノートにすると、直前復習が楽になります。

5過去問の解き方

よくある失敗と対策です。

  • 3種類を曖昧に比較 → 表を見ながら1行ずつ声に出す
  • レインズと35条を混同 → 媒介は仲介契約、35条は売買説明
  • 報酬問題を後回し → 媒介と報酬は同週にセット学習
  • 数字だけ覚える → 誰が・いつ・何を登録するかをセット

業法全体の週配分では、媒介＋報酬で週6時間確保すると業法12問ラインに届きやすくなります。試験直前は比較表のみを毎日5分見返してください。

6よくある質問

媒介契約で一番出るのはどの種類ですか？
3種類すべてから出題がありますが、専任・専属専任はレインズ登録と報酬の条件が複雑で問われやすいです。比較表で横並びにし、過去問で「1項目だけ違う肢」を見抜く練習を重ねてください。一般媒介は「登録不要」などの否定肢が典型です。
レインズ登録はいつまでですか？
専任媒介・専属専任媒介では、成立後2週間以内の登録義務が問題化されます。数字は他の5営業日・7営業日と混同しやすいため、媒介契約専用のカードに分けて暗記してください。過去問で「登録遅延の効果」を確認すると、条文の趣旨が理解しやすくなります。
媒介契約と35条重説の関係は？
媒介契約は仲介依頼の契約、35条は売買等の重要事項説明です。タイミングも役割も異なります。試験では両方の数字が1問に同居することもあるため、「仲介段階」と「売買説明段階」でフロー図を描いて整理すると混同が減ります。業法の学習はフロー図＋比較表の2枚を中心に進めるのが効率的です。
