1相続人と法定相続分

相続・遺留分・遺言は権利関係（14問）の頻出テーマです。民法全体ではなく、宅建過去問に出る範囲に絞ると学習量を抑えられます。

  • 相続人の範囲
  • 遺留分の割合
  • 遺留分減殺請求
  • 遺言の方式が中心

不動産取引では相続登記・遺産分割・複数相続人の売買が実務でも多く、試験でも「誰が売主となるか」「誰の同意が要るか」が事例問題になります。目標は相続関連を含め権利関係14問中8問以上です。

2遺留分

相続人の範囲と順位です。

・配偶者は常に相続人
・子・直系尊属・兄弟姉妹の順位と代襲相続
・養子・離婚・認知の問題は過去問パターンで確認
・遺産分割協議・限定承認・単純承認

図で家族関係を書く習慣をつけると、「叔父が相続人か」などの問題が速く解けます。登記・売買の同意者を問う設問と結びつけて覚えましょう。相続人が複数いる場合の代表権・同意の問題は、過去問でパターンを3つに分類すると復習が速いです。

3遺言の方式

遺留分と遺言です。

・遺留分権者：配偶者・子・直系尊属（兄弟姉妹は遺留分なし）
・遺留分の割合：民法の割合（過去問で計算または判断）
・遺留分侵害額の計算・減殺請求
・遺言方式：自筆証書・公正証書・秘密証書等の要件

2020年改正以降は関連規定の変更があるため、古い問題集は解説の改訂年を確認してください。遺言の方式は表で「何人の証人」「何が必要」を比較します。

4相続放棄・限定承認

過去問演習です。

1. 相続・遺言タグ10問
2. 相続人判断・遺留分計算・遺言方式に分類
3. 抵当権・賃貸借問題と別日に解く（混同防止）
4. 誤答理由を用語解説で1語確認
5. 権利関係セットを25分以内で週1回

相続だけで満点は狙いにくいですが、2〜3問を確実に取ると権利関係全体の合格ラインに届きやすくなります。相続だけに時間を使いすぎず、抵当権・賃貸借との週替わりローテーションを維持してください。

5過去問の解き方

よくある失敗と対策です。

  • 民法全書を読む → 宅建過去問の出題範囲に絞る
  • 遺留分計算を飛ばす → 過去問の型だけ反復
  • 改正前の数字 → 解説の改訂年を確認
  • 登記と切り離し → 売買同意者の問題とセット

権利関係は抵当権・賃貸借と相続で三分割し、週ごとに重点を変えるローテーションが挫折しにくいです。改正民法の確認は、2020年以降の過去問解説を正本にすると安全です。

6よくある質問

相続は民法全体を勉強しますか？
宅建では相続人・遺留分・遺言・遺産分割に絞るのが効率的です。会社法・家族法の周辺は出題頻度が低いため、過去問タグで範囲を確認してください。不動産登記・売買同意の文脈で問題を解くと、実務イメージと試験の両方に役立ちます。
遺留分の計算は毎年出ますか？
毎年とは限りませんが、遺留分権者・割合・侵害の判断は定期的に出ます。計算問題は過去問の型を3パターンに分類し、同型を繰り返すと速くなります。改正後の割合・計算方法は最新解説で必ず確認してください。遺留分と遺言を同じ週に学ぶと、相続分野の得点がまとめて伸びやすいです。
遺言方式の覚え方は？
自筆証書・公正証書・秘密証書などを表で比較し、証人の有無・作成手続の違いを覚えます。過去問では1要件だけ違う選択肢が多いため、表の1行ずつ確認する癖をつけてください。遺言と遺留分は別テーマですが、同週にまとめて学習すると効率が良いです。
