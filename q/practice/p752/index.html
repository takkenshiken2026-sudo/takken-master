宅地建物取引士試験 実践演習 第752問（権利関係）

先取特権について正しいものはどれか。

問題

先取特権について正しいものはどれか。

選択肢

  1. （1） 当事者の契約により発生する担保物権
  2. （2） 法律の規定により当然に生じる法定担保物権
  3. （3） 登記しなければ効力がない
  4. （4） 不動産にのみ成立する

正答

正答は （2） です。

解説

担保物権：抵当権は非占有担保・質権は占有担保・先取特権は法定担保

正解の理由

抵当権は設定者が使用継続できる非占有担保物権です（民法369条）。質権は占有の移転が必要です。先取特権は法律上当然に成立する法定担保物権です。

（2） 法律の規定により当然に生じる法定担保物権

他の選択肢

  • （1） 当事者の契約により発生する担保物権

    この肢は「当事者の契約により発生する担保物権」と述べていますが、権利関係の基準では正しい記述ではありません。

    正答（2）「法律の規定により当然に生じる法定担保物権」は、制度・手続・学習法のいずれかの観点で適切な内容です。

    正答の論点と照らすと、この肢は「当事者の契約により発生する担保物権」という断定のどこかが設問の前提と矛盾します。主語・客体・数字・期限・「毎年／常に／不要」などの限定語をチェックしてください。

学習のヒント

先取特権は法律の規定により当然に生じる法定担保物権です（民法303条）。当事者の契約なしに一定の債権者が他の債権者に優先して弁済を受けられます。一般の先取特権（雇用・日用品費等）と特別の先取特権（動産・不動産）があります。
