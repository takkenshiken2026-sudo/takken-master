宅建の動画・YouTube教材の活用法｜独学での使いどころ

動画は理解の加速に向きますが、視聴だけでは得点になりません。動画のあとに一問一答と過去問でアウトプットを挟む設計が必須です。2026年度試験は10月18日（日）13:00〜15:00・50問・4分野・受験料8,200円（RETIO要項が正本）。本記事では動画教材の向き不向き、1本あたりのアウトプット、通信講座の動画との使い分け、週3時間上限の目安、独学で合格する週次ルーティンを表で整理します。倍速視聴のあとも、必ず過去問3問で理解度を確認してください。

この記事の要点

本記事を読むと、動画教材の向き不向き、1動画あたりのアウトプットの取り方、通信講座の動画との使い分け、視聴のみの日が続いたときの切り替え方が分かります。

  • 視聴だけでは不可
  • 1本後に一問一答5問
  • 動画は週3時間上限
  • 税は過去問中心
  • 直前は動画停止

1動画の役割（独学）

動画・YouTubeは「聞いて理解する」用途に向きます。

  • 業法の条文趣旨
  • 法令制限の図解
  • 権利の事例は視覚と音声で入りやすい

| 向く用途 | 向かない用途 |
| --- | --- |
| 初見の章の概要把握 | 数字・用語の暗記のみ |
| 図解が必要な法令 | 過去問の時間配分練習 |
| 通勤・家事の並行視聴 | 誤答ノートの整理 |

視聴時間は週3時間を上限の目安にし、残りは過去問と一問一答に割り当てます。50問・4分野の模試で36点以上を2回連続が、動画偏重かどうかの判断材料になります。試験日10月18日・受験料8,200円はRETIO要項で再確認してください。

21本あたりのアウトプット

「動画→一問一答→過去問」の順を固定すると、視聴だけで終わる事故が減ります。

| ステップ | 時間目安 | 内容 |
| --- | --- | --- |
| 視聴 | 20〜40分 | 倍速可・メモはキーワードのみ |
| 一問一答 | 10分 | その章から5問 |
| 過去問 | 15分 | 関連論点3問＋解説1行 |

解説で「なぜ正しいか」を1行書けない問題は、テキスト該当ページだけ読み直します。動画とテキストの章番号を対応表にすると、迷いが減ります。視聴のみの日が2日続いたら、翌日は過去問のみに切り替えてください。

3通信講座の動画との使い分け

通信講座の動画はカリキュラム順に進むため、独学のYouTube補助とは役割が異なります。

| ソース | 使い方 |
| --- | --- |
| 講座動画 | カリキュラムどおり・課題提出まで |
| 無料動画 | 弱点章だけ・図解の確認 |
| テキスト | 条文・数字の正本 |
| 過去問 | 得点の正本 |

講座と無料動画を同時にフル活用すると過去問時間が削られます。主役を1つに決め、もう一方は「理解が浅い章だけ」に限定してください。週10時間のうち動画は3時間以内、過去問は4時間以上が目安です。

4分野別の動画の使いどころ

4分野すべてを動画中心にする必要はありません。動画で効く分野と、過去問中心の分野を分けると効率が上がります。

| 分野 | 動画の効き | その後のアウトプット |
| --- | --- | --- |
| 業法 | 高（フロー・数字） | 過去問10問/週 |
| 権利 | 中（事例） | 長文は後回しルール |
| 法令 | 高（図解） | チェックリスト順 |
| 税 | 低（数字中心） | 一問一答15分/日 |

税は動画より数字カードと過去問が主役です。業法35条・媒介は動画で概要→過去問で型暗記の二段構えが向きます。模試で業法12問未満の週は、動画を減らし過去問15問を優先してください。

5週次ルーティンと直前2週間

独学で動画を使う場合の週次例です。過去問量を先にカレンダーに書きます。

| 枠 | 時間 | 内容 |
| --- | --- | --- |
| 平日夜 | 1時間 | 動画1本＋一問一答5問 |
| 休日 | 3時間 | 過去問15問＋誤答メモ |
| 週合計 | 10時間 | 動画≤3時間・過去問≥4時間 |

直前2週間は新規動画を止め、誤答と50問90分の自宅模試だけに切り替えます。2026年10月18日13:00開始は要項どおり。前日は15分の軽い見直しと睡眠を優先します。受験料8,200円・試験形式は申込前に要項PDFで再確認してください。

6よくある質問

YouTubeだけで宅建に合格できますか？
理解の補助としては有効ですが、過去問と一問一答なしでは不足します。動画1本ごとに一問一答5問と過去問3問をセットにしてください。週の動画時間に上限を設け、過去問週4時間以上を確保するのが目安です。50問90分の模試で時間配分を固定すると本番に近づきます。試験日・受験料はRETIOの受験要項が正本です。
倍速で視聴しても大丈夫ですか？
概要把握には有効です。倍速のあとは必ず過去問3問で理解度を確認してください。数字・期限の論点はテキストまたは一問一答で再確認すると混同が減ります。理解が浅い章だけ通常速度で見直す運用で十分です。視聴のみが続く週は、翌週は動画を止め過去問中心に切り替えてください。2026年10月18日の試験日は要項で確認してください。
通信講座の動画と無料動画、どちらを優先しますか？
講座を契約しているなら講座動画を主役にし、無料動画は弱点章の補助に限定するのがおすすめです。独学ならテキスト＋過去問を主役にし、無料動画は図解が必要な章だけ使います。両方をフル併用すると過去問時間が削られるため、主役は1つに決めてください。週10時間・過去問2周が合格設計の基本線です。50問・4分野の配分は要項が正本です。
